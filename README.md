# RDE (RayVen Development Environment)

**RDE** — это автономная мобильная среда разработки (IDE) для Android, созданная **RayVen**. Приложение объединяет мощь Python 3.12 WebAssembly (Pyodide), веб-предпросмотр HTML5/JS и полнофункциональный редактор кода для комфортного программирования прямо на телефоне или планшете.

Проект распространяется по открытой лицензии **MIT**.

---

## 🌟 Основные возможности

- **Локальный Python 3.12 Wasm (Pyodide)**:
  - Выполнение кода Python прямо на устройстве без интернета и удалённых серверов.
  - Поддержка стандартных библиотек (`math`, `sys`, `json`, `datetime` и др.).
  - Интерактивная консоль REPL (`>>>`) с выводом stdout, stderr и возвращаемых значений.

- **Менеджер пакетов Micropip**:
  - Установка чистых Python-модулей и Pyodide-пакетов (`numpy`, `sympy`, `requests`, `pytz` и др.) в один клик.

- **Веб-песочница Live Preview**:
  - Мгновенный предпросмотр HTML5, CSS3 и JavaScript в изолированном `iframe`.

- **Редактор кода (CodeMirror)**:
  - Подсветка синтаксиса для Python, HTML, JavaScript, CSS, JSON, C/C++, Markdown.
  - Нумерация строк, направляющие отступов (indent guides), умное сопоставление скобок.
  - Поиск и замена с поддержкой регистра.

- **Кастомная сенсорная клавиатура**:
  - Поддержка двух раскладок: **QWERTY (EN)** и **ЙЦУКЕН (RU)**.
  - Трёхуровневый Shift с поддержкой **CAPS LOCK** по двойному тапу (в пределах 300 мс) и визуальной подсветкой.
  - **Smart Backspace (Dedent)**: квантованное удаление отступов по 4 пробела за одно нажатие.
  - Защита от потери фокуса: курсор в редакторе остаётся активным при нажатии любых виртуальных клавиш.

- **Файловая система и рабочие пространства**:
  - Полная интеграция с Android Storage Access Framework (SAF).
  - Открытие отдельных файлов и целых папок (workspaces).
  - Сохранение файлов в память устройства и папку «Загрузки».
  - Древовидный проводник файлов и папок.

- **Маркетплейс плагинов и расширений (`rdeAPI`)**:
  - Расширяемая архитектура плагинов на JavaScript.
  - Встроенный каталог плагинов (Lo-Fi радио, форматировщик кода, генератор сниппетов и др.).
  - Импорт пользовательских плагинов `.js` из памяти устройства.
  - Надёжное сохранение и удаление плагинов без случайного восстановления при перезапуске.

## 🛠️ Сборка проекта

### Требования:
- **Android SDK**: API 34+ (compileSdk: 36, minSdk: 24)
- **JDK**: Java 11 или выше
- **Gradle**: 8.x / 9.x (Kotlin DSL)

### Сборка через командную строку:

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/rde.git
   cd rde
   ```

2. Соберите отладочный APK:
   ```bash
   gradle :app:assembleDebug
   ```
   *или с использованием Gradle Wrapper (если настроен):*
   ```bash
   ./gradlew assembleDebug
   ```

3. Готовый APK-файл будет находиться по пути:
   ```
   app/build/outputs/apk/debug/app-debug.apk
   ```
